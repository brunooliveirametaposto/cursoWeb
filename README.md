## GitHub Copilot

Este repositório pode ser utilizado com o GitHub Copilot para auxiliar no aprendizado e desenvolvimento dos exercícios.

### Funcionalidades disponíveis por editor

| Funcionalidade | Visual Studio (IDE) | VS Code |
|---|---|---|
| Completar código automaticamente | ✅ | ✅ |
| Copilot Chat (painel de chat) | ✅ | ✅ |
| Copilot Chat inline (no editor) | ✅ | ✅ |
| Copilot Agent (modo agente autônomo) | ❌ | ✅ |

### Resumo

- **Visual Studio** (IDE completa para .NET/C++): possui Copilot com **completar código** e **Chat**, mas **não possui o modo Agent**.
- **VS Code** (recomendado para desenvolvimento web): possui Copilot com completar código, Chat **e o modo Agent** (disponível nas versões recentes).

Para os exercícios deste curso de desenvolvimento web, recomenda-se o uso do **VS Code**, que oferece suporte completo ao GitHub Copilot, incluindo o modo Agent para tarefas de codificação autônomas.
